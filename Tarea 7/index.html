Resumen HTML: PRINCIPALES CONCEPTOS Y ETIQUETAS

Esta pagina va a resumir los principales conceptos y etiqueticas vistas en la clase de programacion web 1

Conceptos principales HTML

HTML

El Lenguaje de Marcadi de Hipertexto es un lenguaje de marcas que se utiliza para estructurar sitios web.

Elemento HTML

Un elemento HTML es la unidad basica de estructura y contenido en una pagina web y esta compuesta de:

  1. Etiqueta de apertura
  2. Pares de atributo-valor
  3. contenido
  4. Etiqueta de cierre

Etiqueta <head>

es una etiqueta que se utiliza para comunicarse con el navegador a traves de los metadatos, permite mejorar el SEO, ademas se enlazab archivos externos de estilos o scripts

Etiqueta <head>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semanticos

<header> Es una etiqueta utilizada para el contenido introductorio para una pagina web, puede contener el logo, el menu de navegacion principal, el nombre de la empresa, etc.
<NAV> Etiqueta utilizada para el menu de navegacion principal, suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal, no debe de haber mas de una en la pagina
<MAIN> Etiqueta unica de una pagina web, cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra pagina
<ARTICLE> Es una etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de encabezado y contenido
<Footer> Es una etiqueta que normalmente se encuentra hasta el final de una pagina y funciona como cierre de sitio web, amenudo contiene datos de contacto, derecho de autor u otra informacion complementaria
<ASIDE> Esta etiqueta representa una seccion de la pagina web cuyo contenido no esta relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados etc.
