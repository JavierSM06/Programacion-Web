Tipos de estilo en CSS

Estilos en linea

Se van a agregar directamente en el elemento HTML mediante el atributo style pero puede dificultar la mantenibilidad del codigo si se abusa de esta tecnica.

Este parrafo tiene estilos en linea

Estilos internos

Estos estilos se agregan en el mismo archivo HTML dentro de la etiiqueta style en la seccion <head> y para agregarlos se utiliza el elemento <style>

Estilos externos

Estos estilos son los que se recomiendan utilizar ya que ofrecen modularidad, facilidad de mantenimiento, orden, eficencia entre otras ventajas. Para agregar una hoja de estilos externa dentro de la etiqueta <head> se utiliza el el elemento <link> donde especificaremos la ruta del archivo CSS y usamos el atributo rel establecido en stylesheet y el atributo href apuntando a la ubicacion del archivo CSS
